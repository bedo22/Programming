The Shelf — Every Doc, Every Lesson, Both Languages

One entry point for the whole shelf: the reference docs grouped by layer, each with its Arabic version when one exists; the lesson journey; and the supporting material. The glossary remains the learning map — layer structure, ownership, deliberate absences, shared vocabulary; this page is navigation: everything, in one place, in both languages.

How to use this page

  • Docs: each band is one layer of the glossary map (the layer name sits on its own divider row); each row below it pairs the English doc with its Arabic version (when it exists).
  • Lessons: the numbered journey, 0001 → 0022. Reference docs point into the lessons; lessons point back into the docs.
  • Language: every reference doc carries a Language line in its header linking to its twin.
  • New material: when a doc or lesson is added, add one row here — that is the full cost of keeping the front door current.
