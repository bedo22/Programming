# RESOURCES-FORMAT.md

The format for `RESOURCES.md` — the curated list of high-trust resources that ground the
teaching. **Never trust parametric knowledge.** Every claim in a lesson should trace back
to an entry here.

## Entry shape

One block per resource, grouped by topic. Use this template:

```
### <Resource title>
- **Type:** Book / Paper / Docs / Spec / Video / Article / Community
- **URL:** https://… (verify the link resolves before adding)
- **Trust:** High / Medium — and why (e.g. official spec, creator-authored, peer-reviewed)
- **Grounds:** which episodes/lessons this backs
- **Notes:** access limits (paywall?), language, what to read first
```

## Rules
- Prefer primary sources (specs, creator writings, peer-reviewed papers) over secondary.
- Verify each URL resolves before listing it. Note paywalls explicitly.
- Group by topic heading (`## Language & history`, `## React`, etc.).
- Re-strike resources that turn out to be low-trust — keep the list honest.
- One recommended *primary* source per lesson is drawn from this list.
