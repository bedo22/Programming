# FINDINGS.md — toolchain findings (this shelf's write surface)

Corpus lanes record, they don't fix. A problem found while running the
shelf-pipeline tooling gets a row HERE — with the failing case (exact
command + file + output line) — then goes upstream through the maintain
lane's promotion pass (skill `references/MAINTAINING.md` §3). Before
fixing anything yourself, read this file AND the skill's
`IMPROVEMENT-LEDGER.md` — the problem may already be classified or fixed.

Row grammar (identical to the skill ledger's Bugs table):

| Date | Corpus/session | Finding | Family | Failing case | Status |
|---|---|---|---|---|---|

Statuses: `open — upstream` · `triaged → <date>` · `corpus-local fixed (receipt)` · `rejected (why)`
